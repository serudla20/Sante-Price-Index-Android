# Sante-Price Index – Android App Development using GenAI

## Project Overview
Sante-Price Index is a modern Android application developed using Kotlin and Jetpack Compose to help users compare medicine and healthcare product prices efficiently. The application provides secure user authentication, product management, profit calculation, and Firebase-based cloud integration through a clean and responsive user interface.

The project focuses on solving real-world healthcare product pricing challenges while demonstrating modern Android application development practices using Jetpack Compose and Firebase services.

---

# Project Objectives

- Develop a modern Android application using Kotlin
- Implement secure Firebase Authentication
- Store and manage product data using Firebase Realtime Database
- Create a responsive and user-friendly interface using Jetpack Compose
- Implement medicine/product price comparison features
- Develop a profit calculator module
- Demonstrate frontend and backend integration in Android development

# Installation Steps

## Step 1: Clone Repository

```bash
git clone https://github.com/yourusername/Sante-Price-Index.git
```

---

## Step 2: Open in Android Studio

- Launch Android Studio
- Select Open Project
- Choose the cloned project folder

---

## Step 3: Configure Firebase

- Create Firebase Project
- Enable Authentication
- Enable Realtime Database
- Download `google-services.json`
- Place the file inside the app folder

---

## Step 4: Sync Gradle

- Sync Gradle Dependencies
- Build the Project

---

## Step 5: Run Application

- Connect Android Device or Emulator
- Click Run Button in Android Studio

---

# Firebase Setup

## Firebase Configuration Steps

1. Open Firebase Console
2. Create New Firebase Project
3. Register Android Application
4. Add SHA-1 Key
5. Download `google-services.json`
6. Place file inside app directory
7. Enable Firebase Authentication
8. Enable Firebase Realtime Database
